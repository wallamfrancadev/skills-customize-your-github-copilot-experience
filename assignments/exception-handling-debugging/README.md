# 📘 Assignment: Exception Handling & Debugging

## 🎯 Objective

Master error handling and debugging techniques to write robust, production-ready Python code. Students will learn how exceptions work, implement proper error handling strategies, and use debugging tools to identify and fix issues efficiently.

## 📝 Tasks

### 🛠️ Task 1: Understand and Catch Exceptions

#### Description
Learn how to handle common Python exceptions using try-except blocks to prevent program crashes and provide meaningful error messages.

#### Requirements
Completed program should:

- Use try-except blocks to catch specific exception types (ValueError, TypeError, FileNotFoundError, etc.)
- Provide user-friendly error messages for different exception types
- Demonstrate catching multiple exception types in a single error handler
- Show the difference between catching specific vs. generic exceptions


### 🛠️ Task 2: Implement Proper Exception Handling Patterns

#### Description
Write code that handles errors gracefully using except-else-finally blocks and custom error messages for better user experience.

#### Requirements
Completed program should:

- Use else clause to execute code only if no exception occurred
- Use finally clause for cleanup operations (closing files, releasing resources)
- Implement proper exception handling in functions and methods
- Log or report errors appropriately


### 🛠️ Task 3: Debug Code with Print Statements and Logging

#### Description
Use debugging techniques to identify bugs and trace program execution using both manual debugging and Python's logging module.

#### Requirements
Completed program should:

- Add strategic print statements to trace variable values and program flow
- Configure Python's logging module with appropriate levels (DEBUG, INFO, WARNING, ERROR)
- Use logging instead of print statements for production code
- Enable/disable debugging output without changing code logic


### 🛠️ Task 4: Raise and Handle Custom Exceptions (Stretch Goal)

#### Description
Create custom exception classes and raise them when appropriate to handle domain-specific errors in your programs.

#### Requirements
Completed program should:

- Define custom exception classes that inherit from Exception
- Raise custom exceptions with meaningful error messages
- Handle custom exceptions appropriately in calling code
- Document when and why custom exceptions are raised
